Конфиденциальность QR-инструментов

Редакция от 12 ноября 2026 года.

Эта политика — о бесплатных QR-инструментах clx: генераторе QR-кодов на этом сайте, API QR-кодов на qr.clx.cx и расширении для браузера (его страница). Ни одному из них не нужна учётная запись, ни один не ставит cookie, не показывает рекламу и не ведёт аналитику. Политика для учётных записей clx — отдельная страница.

Генератор на сайте

QR-код рисуется в вашем браузере. Введённый текст никуда не отправляется: страница не делает с ним запросов. Ссылка на картинку и HTML-код тоже собираются в браузере; до API они доходят, только когда их кто-то открывает. Генератор не сохраняет ничего из введённого и не ставит cookie; что хранит сам сайт — тему, код партнёра из ссылки, — описано на странице конфиденциальности clx.

API на qr.clx.cx

API получает запрос, когда открывают ссылку на него, — вы или браузер любого, кто смотрит страницу или письмо с такой картинкой. Запрос несёт текст для кодирования, размер, коррекцию ошибок и поле, а ещё, как любой запрос в вебе, IP-адрес зрителя, его браузер (User-Agent) и часто страницу, с которой он пришёл (Referer). API:

  • использует текст только чтобы нарисовать картинку и проверить хеш ссылки;
  • не ведёт журналов запросов и не хранит картинок; только ответы /qr.inline 24 часа лежат в кеше Cloudflare по полному адресу, потом истекают;
  • никого не считает, не профилирует и не отслеживает.

QR-код — не тайна: его текст прочтёт любой, у кого есть ссылка или кто его отсканирует. Не кодируйте пароли и другие секреты.

Расширение для браузера

С версии 1.1.0 расширение вообще не делает сетевых запросов: коды и ссылки создаются в браузере. Версии до 1.1.0 отправляли текст каждого созданного кода в API по старому адресу, qr.qrcgen.com. Разрешения расширения:

  • боковая панель — чтобы показать своё окно (Chrome, Edge; в Firefox — боковая колонка без разрешения);
  • хранилище — чтобы держать настройки (тема, размер и коррекция по умолчанию, размер истории, создание при открытии) и историю кодов, ссылку на которые вы копировали, только в вашем браузере;
  • вкладки — чтобы прочитать адрес текущей страницы и сделать её код.

Ничто из сохранённого расширением не покидает браузер и не синхронизируется; удаление расширения удаляет и это.

Кто обрабатывает данные

API и страницы сайта работают на Cloudflare (Workers), кроме русских страниц (ru.clx.cx) — они на GitHub Pages; каждый обрабатывает свои запросы как хостинг и по своей политике. Из России картинки с qr.clx.cx могут не открываться без VPN; генератор на ru.clx.cx рисует код в браузере и от API не зависит. Мы не подключаем аналитику ни Cloudflare, ни чью-либо ещё; видим только число запросов и ошибок, которое Cloudflare показывает любому аккаунту, без их содержимого. Данные не продаются и никому не передаются.

Дети

QR-инструменты намеренно не собирают ничьих личных данных, в том числе детских, и ничего не хранят, кроме описанного выше суточного кеша /qr.inline; что несёт сам запрос, описано там же.
