Открытый код clx

Сервис clx.cx, воркер, который он ставит в ваш аккаунт Cloudflare, и этот сайт — один публичный репозиторий под AGPL-3.0. Проверьте, что работает в вашем аккаунте, или запустите свой clx.

Начать бесплатно

AGPL-3.0

Код можно читать, менять и запускать. Если вы даёте изменённую копию другим как сервис, её пользователи тоже получают исходный код.

Что работает в вашем аккаунте

Воркер собирается из папки edge/ репозитория; собранный бандл коммитится со своим sha256, а рядом — список всех когда-либо выпущенных. clx заменяет или удаляет воркер в вашем аккаунте, только если его код — один из них.

Свой clx

Сам clx.cx — это Worker с базой D1 и пространством KV: копию запускает один аккаунт Cloudflare, с тем же кабинетом, API и воркером для аккаунтов ваших пользователей.

Библиотека QR-кодов

QR-коды рисует @spintax/qr-svg — отдельная библиотека в npm под лицензией MIT, без собственных зависимостей.

Запустить свою копию

Нужны Node.js 22 и pnpm. Все шаги, включая секреты, — в README.

git clone https://github.com/investblog/clx && cd clx
pnpm install
node scripts/wrangler.mjs login
node scripts/wrangler.mjs d1 create clx
node scripts/wrangler.mjs kv namespace create SESSIONS
cp wrangler.example.jsonc wrangler.jsonc   # ваш маршрут, id, HOOK_URL
node scripts/wrangler.mjs d1 migrations apply clx --remote
node scripts/secrets.mjs JWT_SECRET
node scripts/secrets.mjs MASTER_KEYS
pnpm run deploy
node scripts/user.mjs add you@example.com
