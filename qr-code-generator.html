Бесплатный генератор QR-кодов в SVG

Введите адрес или любой текст: QR-код рисуется в вашем браузере как лёгкий SVG — один прямоугольник и один контур, чёткий в любом размере. Скачайте его, скопируйте или возьмите ссылку на ту же картинку для своей страницы.

Почему SVG

Векторный QR-код остаётся чётким на телефоне, в печати и на баннере. Этот весит около 3 КБ для короткого адреса: белый прямоугольник и один контур в целых координатах, больше ничего — его легко править, вставить в HTML и пропустить через любой конвейер.

Ничего не уходит из браузера

Код рисуется на этой странице открытой библиотекой @spintax/qr-svg. Введённый текст никуда не отправляется — ни один запрос его не несёт, — а генератору не нужна учётная запись и он не ставит cookie.

Ссылка на ту же картинку

Ссылка на картинку ведёт на бесплатный API qr.clx.cx — он рисует тот же самый SVG по тексту из ссылки. Вставьте её в тег <img>, README или письмо; текст лежит в самой ссылке, поэтому мы ничего не храним. API работает на Cloudflare: из России такие картинки могут не открываться без VPN — тогда скачайте SVG.

Считайте сканирования

Обычный QR-код не скажет, кто его отсканировал. Направьте его на короткую ссылку clx на вашем домене — сканирования посчитаются отдельным источником, по странам и устройствам. Бесплатно, в вашем аккаунте Cloudflare.

Вопросы

Генератор бесплатный?

Да, без регистрации и без ограничения числа кодов: они рисуются в вашем браузере. API qr.clx.cx тоже работает без ключа.

Как открыть страницу с компьютера на телефоне?

Вставьте сюда адрес страницы, отсканируйте код камерой телефона и нажмите появившуюся ссылку — страница откроется на телефоне, без пересылки ссылки самому себе и без входа в аккаунт. Расширение для браузера избавляет от вставки: оно делает код открытой страницы.

Есть расширение для браузера?

Да, бесплатное: SVG QR Code Generator для Chrome, Firefox и Edge. В боковой панели оно делает QR-код для открытой страницы или любого текста — SVG, ссылку и код для вставки, как здесь, — и ничего никуда не отправляет.

QR-коды отсюда перестают работать?

Нет. QR-код хранит текст в себе и работает, пока работает то, куда он ведёт. Ссылка на картинку работает, пока работает API.

Какую коррекцию ошибок выбрать?

M — для экранов и большинства печати; Q или H — для печати, которую могут поцарапать, или если поверх кладётся логотип. Чем выше уровень, тем плотнее код.

Можно поменять, куда ведёт напечатанный код?

С обычным QR-кодом — нет: его текст неизменен. Закодируйте короткую ссылку и меняйте её цель когда угодно.

QR-код — это тайна?

Нет. Любой, кто его отсканирует или откроет ссылку на картинку, прочтёт текст. Не кодируйте пароли и другие секреты.
