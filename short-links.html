Сокращатель ссылок на вашем домене

Короткие ссылки на ваших доменах, свой хост у каждого сайта, например k7q.example.com, — их обслуживает воркер в вашем аккаунте Cloudflare: с QR-кодом для каждой ссылки, правилами по стране и устройству и статистикой кликов.

Пример ссылки.

Ваш домен, а не наш

У каждого сайта может быть свой хост ссылок — случайное имя из трёх символов под его адресом, например k7q.example.com, — так что ссылки одного сайта ничем не связаны с другим. Хост clx создаёт сам: DNS-запись и сертификат делает Cloudflare, и никогда поверх вашей записи. Ссылка отвечает обычным редиректом 302 без кеширования, так что каждый клик доходит до воркера; всё остальное на хосте — пустой 404.

QR-код для каждой ссылки

Скачайте его в SVG в кабинете или через API. Сканирование учитывается отдельным источником, а код ссылки не меняется: смените цель или правила — напечатанные коды продолжат работать.

Правила по стране и устройству

До десяти правил на ссылку: Германию — на немецкую страницу, телефоны — в приложение. Срабатывает первое подходящее правило, иначе — основная цель.

Статистика кликов

Клики и посетители каждой ссылки по дням — с источниками, странами, устройствами, браузерами и системами, а у ссылки с правилами — какое правило забрало какие клики. Боты тоже переадресуются, но считаются отдельно.

Какое правило забрало какие клики

С правилами одна ссылка ведёт людей разными путями. Отчёт рисует это одной картинкой: от каждого источника — к адресу, куда ушёл клик. Сразу видно, что на деле делает каждое правило.

Отчёт этой ссылки за 30 дней: напечатанный QR-код раздавали в Германии, а блог читают с телефонов.

Ссылка — один вызов API

Создавайте ссылки в кабинете или поручите это генератору сайтов или агенту:

curl https://clx.cx/v1/links \
  -H "Authorization: Bearer clx_…" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"link_host_id":"…","url":"https://example.com/spring-sale","code":"spring",
       "rules":[{"countries":["DE","AT"],"url":"https://example.de/fruehling"}]}'

# → 201 { "link": { "short_url": "https://k7q.example.com/spring", … } }

Вопросы

Можно без своего домена?

Нет. Ссылки живут на вашем хосте в вашем аккаунте Cloudflare: через clx.cx ваш трафик не идёт.

Что будет с напечатанным QR-кодом, если страница переедет?

Поменяйте цель ссылки: код ссылки и QR-код останутся прежними.

Сколько ссылок можно сделать?

200 на бесплатном тарифе, 10 000 на тарифе API.

Как выбирается страна?

По стране, из которой Cloudflare видит клик; устройство — телефон или компьютер.

Работают ли ссылки для посетителей из России?

Да. Российские провайдеры обрывают соединения с Cloudflare после первых ~16 КБ, а переход по ссылке — это редирект 302 без тела: вместе с TLS-рукопожатием меньше 5 КБ. Дальше посетитель уходит на целевой адрес — как тот открывается в России, зависит уже от его хостинга.
