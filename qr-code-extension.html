SVG QR Code Generator

SVG QR Code Generator — бесплатное расширение для браузера: QR-код в боковой панели для открытой страницы или любого текста, лёгким SVG, со ссылкой и готовым кодом для вставки. Оно ничего никуда не отправляет.

Установить

Chrome Web StoreFirefox Add-onsMicrosoft Edge Add-ons

Начало

  • Нажмите значок расширения — откроется боковая панель (в Firefox — боковая колонка).
  • С настройкой «Авто-генерация при открытии» она сразу покажет QR-код текущей страницы.
  • Чтобы открыть ту же страницу на телефоне, отсканируйте код камерой телефона и нажмите появившуюся ссылку — не нужно пересылать её самому себе.
  • Скопируйте ссылку, скопируйте или скачайте SVG, либо возьмите сниппет на вкладке «Код».

Создать

  • «Текущая страница» — адрес активной вкладки; после перехода на другую страницу нажмите кнопку обновления.
  • «Свой текст» — любой адрес или текст, до 2 048 символов (эмодзи считается за два).
  • Размер: 125, 200, 250 или 300 px. ECC (коррекция ошибок): L 7%, M 15%, Q 25%, H 30% — выше уровень, прочнее код, но плотнее.
  • «Скопировать ссылку» — ссылка на картинку в API QR-кодов, с текстом внутри; для текста длиннее 2048 символов её нет. «Скопировать SVG» и «Скачать SVG» работают для любого кода.

Код

  • Сниппеты с той же ссылкой: HTML <img>, HTML <object>, Markdown, React и Vue — «Скопировать сниппет» или «Скопировать URL», если нужна только ссылка.
  • Ссылки, скопированные в версиях до 1.1.0, не содержали текста и больше не работают: скопируйте их заново из истории.

История и настройки

  • Код попадает в историю, когда вы нажимаете «Скопировать ссылку» на вкладке «Создать»: текст, время, размер и ECC. «Очистить» удаляет историю.
  • Настройки: размер и уровень ECC по умолчанию, «Авто-генерация при открытии», «Лимит истории» (25, 50 или 100), тема.
  • История и настройки хранятся в вашем браузере (storage.local) и не синхронизируются.

Приватность и разрешения

  • С версии 1.1.0 расширение не делает сетевых запросов: коды и ссылки создаются в браузере. Прежние версии отправляли текст каждого кода старому API.
  • Ссылка несёт свой текст: его прочтёт любой, кто её откроет или отсканирует код. Картинки по ссылкам рисует API на Cloudflare — из России они могут не открываться без VPN; SVG из расширения работает везде.
  • Разрешения: боковая панель (окно расширения; в Firefox — боковая колонка, разрешение не нужно), хранилище (настройки и история), вкладки (адрес текущей страницы).

Политика целиком: конфиденциальность QR-инструментов. API, на который ведут его ссылки: qr.clx.cx.
